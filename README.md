## Избранные проекты


CUT — сайт современного барбершопа

[![CUT](https://raw.githubusercontent.com/vbnmsa/CUT/main/public/cut-hero.png)](https://github.com/vbnmsa/CUT)

Адаптивный сайт московского барбершопа с полноценным сценарием онлайн-записи. Пользователь может выбрать услугу и мастера, подобрать дату и доступное время, применить специальное предложение и оформить визит.

**Что реализовано:**

- каталог услуг с ценами и продолжительностью;
- карточки барберов со специализацией и рейтингом;
- выбор мастера, даты и времени;
- онлайн-запись и проверка контактных данных;
- акции, подарочные сертификаты, отзывы и FAQ;
- адаптивный интерфейс и hero-анимация;
- автоматизированные проверки безопасности.

**Стек:** React · TypeScript · Vite · Tailwind CSS · Lucide React

[Открыть сайт](https://cutt-psi.vercel.app/)   [Посмотреть код](https://github.com/vbnmsa/CUT)

### NORTH WASH — сайт премиальной автомойки

[![NORTH WASH](https://raw.githubusercontent.com/vbnmsa/NORTHWASH/main/public/og.png)](https://northwashh-8o2m.vercel.app/)

Интерактивный лендинг автомойки и детейлинг-студии в Москве. Пользователь может выбрать автомобиль, сравнить тарифы, подобрать дату и время, а затем оформить запись.

**Что реализовано:**

- адаптивный дизайн для компьютеров, планшетов и телефонов;
- интерактивные тарифы для Sedan и SUV;
- поиск по 47 маркам и 188 моделям автомобилей;
- автоматическое определение категории автомобиля;
- выбор даты и доступного времени записи;
- анимированное подтверждение с данными клиента;
- Canvas-анимации и управление фоновым звуком через Web Audio API.

**Стек:** HTML5 · CSS3 · JavaScript · Canvas API · Web Audio API · Node.js

[Открыть сайт](https://northwashh-8o2m.vercel.app/) · [Посмотреть код](https://github.com/vbnmsa/NORTHWASH)
